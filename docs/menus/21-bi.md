# 21 — BI (Business Intelligence)

**Ícono sugerido:** `line-chart`
**Tipo:** Consumidor de solo lectura (sin datos propios) — ver
[04-catalogo-modulos-negocio.md](../architecture/04-catalogo-modulos-negocio.md#bi-vs-reportes-por-qué-son-módulos-distintos)
**Descripción:** Tableros interactivos, KPIs e indicadores de gestión
con navegación multidimensional (drill-down, comparación entre
períodos). A diferencia de `reportes`, la unidad de trabajo es el
análisis exploratorio, no la salida formal impresa.
**Módulos relacionados:** consume el modelo analítico agregado
(típicamente ya pasado por `reportes`), no las tablas transaccionales
directamente.

## Submenú: Tableros (Dashboards Analíticos)

### Formularios

| Formulario      | Qué hace                                                  | Tablas principales                | Permiso    | Documento que genera |
| --------------- | --------------------------------------------------------- | --------------------------------- | ---------- | -------------------- |
| Tablero BI      | Define un tablero con un conjunto de indicadores/gráficos | `bi.tablero`, `bi.tablero_widget` | `bi.crear` | —                    |
| Indicador (KPI) | Define una métrica de negocio con su fórmula y meta       | `bi.indicador`                    | `bi.crear` | —                    |

### Acciones

| Acción                        | Qué hace                                                                                                | Permiso                                  | Efecto/Evento |
| ----------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------- |
| Compartir Tablero con Rol     | Habilita que un rol vea un tablero                                                                      | `bi.configurar`                          | —             |
| Exportar Tablero a PDF/Imagen | Genera una instantánea del tablero para compartir fuera del sistema                                     | `bi.exportar`                            | —             |
| Drill-down                    | Navega desde un valor agregado hacia su detalle transaccional (delega en la consulta del módulo origen) | `bi.ver` (+ `.ver` del módulo de origen) | —             |

## Submenú: Indicadores por Área

| Área             | Ejemplos de KPI                                                    |
| ---------------- | ------------------------------------------------------------------ |
| Comercial        | Venta acumulada vs. meta, ticket promedio, tasa de conversión CRM  |
| Financiero       | Liquidez, días de cobro/pago, margen neto                          |
| Operaciones      | Rotación de inventario, cumplimiento de entrega, OEE de producción |
| Recursos Humanos | Rotación de personal, ausentismo, costo laboral por ingreso        |
| Proyectos        | Rentabilidad por proyecto, desvío presupuestario                   |

Cada KPI referencia la fuente de datos del módulo correspondiente (ver
tabla de índice en [20-reportes.md](./20-reportes.md#submenú-catálogo-de-reportes)).

## Submenú: Análisis Multidimensional

| Elemento                              | Detalle                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Consulta — Análisis por Dimensión     | Qué muestra: un indicador cruzado libremente por dimensiones disponibles (tiempo, sucursal, producto, cliente, vendedor) | Permiso: `bi.ver` |
| Consulta — Comparación entre Períodos | Qué muestra: variación de un indicador entre dos períodos seleccionables                                                 | Permiso: `bi.ver` |

## Submenú: Alertas Inteligentes

| Elemento                            | Detalle                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------- |
| Formulario — Alerta sobre Indicador | Qué hace: define un umbral que, al superarse, notifica a un rol/usuario | Tablas: `bi.alerta` | Permiso: `bi.crear` |
| Consulta — Alertas Disparadas       | Qué muestra: historial de alertas activadas                             | Permiso: `bi.ver`   |

## Configuraciones del módulo

| Parámetro                                        | Qué controla                                                         |
| ------------------------------------------------ | -------------------------------------------------------------------- |
| Frecuencia de actualización del modelo analítico | Cada cuánto se recalculan los agregados que alimentan los tableros   |
| Tableros por defecto por rol                     | Qué tablero ve cada rol al entrar al módulo                          |
| Retención de histórico analítico                 | Cuánto tiempo se conserva el detalle para comparación entre períodos |
