# Modelo Lógico — HR (`hr`)

Referencia `core.departments` (jerárquico) — no declara su propia
estructura organizacional. Los documentos del legajo usan
`core.documents`. Alimenta a `payroll`, nunca al revés.

## Legajo

| Tabla                         | Propósito                                                           | FKs no-universales                                                                                |
| ----------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `employees`                   | Ficha de empleado: datos civiles, contacto, cuenta bancaria de pago | `department_id → core.departments`, `user_id → core.users` (opcional)                             |
| `employee_contracts`          | Contrato laboral vigente/histórico                                  | `employee_id → employees`, `contract_type_id → contract_types`, `job_position_id → job_positions` |
| `contract_types`              | Catálogo (indefinido, plazo fijo, por obra)                         | `company_id`                                                                                      |
| `job_positions`               | Puesto/cargo con banda salarial                                     | `department_id → core.departments`                                                                |
| `employee_emergency_contacts` | Contacto de emergencia                                              | `employee_id → employees`                                                                         |
| `employee_dependents`         | Dependiente para beneficios/seguro                                  | `employee_id → employees`                                                                         |
| `employee_bank_accounts`      | Cuenta bancaria para pago de nómina                                 | `employee_id → employees`                                                                         |
| `skills_catalog`              | Catálogo de habilidades/competencias                                | `company_id`                                                                                      |
| `employee_skills`             | Habilidades de un empleado con nivel (N:M)                          | `employee_id → employees`, `skill_id → skills_catalog`                                            |

## Asistencia y ausencias

| Tabla                          | Propósito                                                                               | FKs no-universales                                                                                         |
| ------------------------------ | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `attendance_devices`           | Dispositivo de marcación (biométrico, tarjeta)                                          | `branch_id`                                                                                                |
| `attendance_records`           | Marcación de entrada/salida                                                             | `employee_id → employees`, `device_id → attendance_devices`                                                |
| `leave_types`                  | Catálogo (vacaciones, enfermedad, maternidad/paternidad, sin goce) con regla de cómputo | `company_id`                                                                                               |
| `leave_requests`               | Solicitud de ausencia                                                                   | `employee_id → employees`, `leave_type_id → leave_types`                                                   |
| `leave_request_status`         | Catálogo de estados                                                                     | `company_id`                                                                                               |
| `leave_request_status_history` | Historial de transición (aprobación/rechazo)                                            | `leave_request_id → leave_requests`, `status_id → leave_request_status`, `decided_by_user_id → core.users` |
| `vacation_balances`            | Saldo de vacaciones acumulado/tomado por empleado y año                                 | `employee_id → employees`                                                                                  |

## Desempeño y capacitación

| Tabla                             | Propósito                                     | FKs no-universales                                                                         |
| --------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `performance_evaluations`         | Evaluación periódica                          | `employee_id → employees`, `evaluated_by_user_id → core.users`                             |
| `performance_evaluation_criteria` | Competencia evaluada                          | `company_id`                                                                               |
| `performance_evaluation_scores`   | Puntaje por criterio dentro de una evaluación | `evaluation_id → performance_evaluations`, `criteria_id → performance_evaluation_criteria` |
| `trainings`                       | Curso/entrenamiento disponible                | `company_id`                                                                               |
| `training_enrollments`            | Inscripción de un empleado a una capacitación | `training_id → trainings`, `employee_id → employees`                                       |
| `disciplinary_action_types`       | Catálogo (llamado de atención, suspensión)    | `company_id`                                                                               |
| `disciplinary_actions`            | Acción disciplinaria registrada               | `employee_id → employees`, `action_type_id → disciplinary_action_types`                    |

## Reclutamiento y selección

| Tabla                     | Propósito                                                     | FKs no-universales                                         |
| ------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| `job_vacancies`           | Posición abierta                                              | `job_position_id → job_positions`                          |
| `candidates`              | Postulante a una vacante                                      | `vacancy_id → job_vacancies`                               |
| `candidate_stages`        | Catálogo del proceso (CV, entrevista, prueba técnica, oferta) | `company_id`                                               |
| `candidate_stage_history` | Avance del candidato por etapa                                | `candidate_id → candidates`, `stage_id → candidate_stages` |

## Activos asignados

| Tabla                        | Propósito                                                                        | FKs no-universales                                                      |
| ---------------------------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `employee_asset_assignments` | Activo fijo de la empresa (laptop, vehículo, herramienta) asignado a un empleado | `employee_id → employees`, `asset_id → assets.fixed_assets` (ID suelto) |
