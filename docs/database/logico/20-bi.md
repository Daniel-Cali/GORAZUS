# Modelo Lógico — BI (`bi`)

Consume agregados ya materializados (ver
[28_materialized_views.sql](../sql/28_materialized_views.sql)), no las
tablas transaccionales crudas — las tablas de este módulo son
metadatos de análisis y snapshots históricos para comparación entre
períodos, no el detalle operativo.

| Tabla                  | Propósito                                                               | FKs no-universales                                              |
| ---------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------- |
| `data_mart_tables`     | Registro de qué vista materializada alimenta qué análisis               | `company_id`                                                    |
| `data_cubes`           | Cubo analítico definido (ventas por dimensión, por ejemplo)             | `data_mart_table_id → data_mart_tables`                         |
| `data_cube_dimensions` | Dimensión disponible en un cubo (tiempo, sucursal, producto, cliente)   | `cube_id → data_cubes`                                          |
| `data_cube_measures`   | Métrica agregable del cubo (suma, promedio, conteo)                     | `cube_id → data_cubes`                                          |
| `kpis`                 | Indicador clave de negocio con fórmula y meta                           | `company_id`                                                    |
| `kpi_snapshots`        | Valor calculado de un KPI en un momento dado (para tendencia histórica) | `kpi_id → kpis`                                                 |
| `indicators`           | Indicador de menor jerarquía que un KPI (detalle operativo)             | `company_id`                                                    |
| `indicator_snapshots`  | Valor histórico de un indicador                                         | `indicator_id → indicators`                                     |
| `metrics`              | Métrica cruda agregable (sin meta asociada, a diferencia de KPI)        | `company_id`                                                    |
| `metric_snapshots`     | Valor histórico de una métrica                                          | `metric_id → metrics`                                           |
| `forecast_models`      | Modelo de pronóstico configurado (algoritmo, parámetros)                | `company_id`                                                    |
| `forecasts`            | Resultado de pronóstico generado por un modelo                          | `model_id → forecast_models`                                    |
| `bi_alerts`            | Umbral definido sobre un KPI/indicador/métrica                          | `kpi_id → kpis` (o `indicator_id`/`metric_id`, uno de los tres) |
| `bi_alert_triggers`    | Registro de cada activación de una alerta                               | `alert_id → bi_alerts`                                          |

**Total: 14 tablas.**
